# 🌐 NithishSJ Portfolio

A modern personal portfolio website built with **Next.js**, showcasing my projects, technical expertise, professional experience, certifications, and career journey in Data Engineering, Microsoft Fabric, Analytics, and Business Intelligence.

---

## Repository Structure

```text
nithishsj-portfolio/
│
├── app/                 # Application routes & pages
├── components/          # Reusable UI components
├── public/              # Static assets
├── content/             # Project & blog content
├── lib/                 # Utility functions
├── types/               # TypeScript definitions
├── hooks/               # Custom React hooks
├── docs/                # Project documentation
│
├── package.json
├── next.config.ts
├── tsconfig.json
└── README.md
```

---

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
- Vercel
